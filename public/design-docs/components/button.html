Components · 액션

Button (버튼)

브랜드 1차 액션 컴포넌트. 5변형 = arch(주 CTA) · navy · outline · light · teal(보조 CTA) — 홈페이지 실측 정본(design.md §7, 2026-07-26 대표 승인). 전 변형이 완전 원형(--button-radius = full) 이고, 높이는 40/48/56 3단 스케일이다.

정의

사용자가 누르면 즉시 액션이 실행되는 컴포넌트다. 사각 버튼은 이 브랜드에 없다 — 필(pill) 형태가 "누르는 것"의 시그니처이며, 인풋(12px 모서리)과 형태로 구분된다.

Anatomy

부위토큰
① 컨테이너모서리 --button-radius(full 고정) · 높이 --button-height-sm/md/lg(40/48/56px) · 좌우 --button-pad-x-sm/md/lg(20/24/28px)
② 라벨--font-family-sans · 크기 --font-size-base(15px) · 굵기 --font-weight-semibold(600) · 줄바꿈 금지
③ 아이콘(선택)라인 SVG, 라벨과 간격 --button-gap, stroke="currentColor"

변형

변형용도
arch화면의 주 CTA(한 화면 1개) — 아치 그라디언트 필 + 흰 라벨 + 컬러 그림자
navy보조 액션 기본 — 네이비 필 + 흰 라벨, 호버 시 청록으로 전환
outline3차 액션 — 흰 배경 + 헤어라인 보더, 호버 시 청록 보더·라벨
light진한 면(네이비 밴드·아치 밴드) 위 전용 — 흰 필 + 네이비 라벨
teal보조 CTA(외부·별도 목적지) — primary-strong(#0B6C7D) 필. 네이비 반전 밴드가 있는 페이지에서 navy 대신 쓴다: 버튼과 밴드가 같은 네이비면 버튼이 그 섹션으로 가는 링크처럼 읽힌다(2026-07-26 대표 지적)

라임 단색 CTA는 웹 금지(design.md §8 — 라임·노랑은 구조를 칠하지 않는다). 인쇄 뒷표지의 라임 필은 paged.css 관할로 별개.

Do / Don't

Do
  • 한 화면에 arch는 1개만 — 주 액션이 무엇인지 시선이 바로 가게 한다.
  • 헤더 우측 = navy(주) + outline 또는 teal(보조), 높이 40px(--button-height-sm).
  • 같은 대상을 히어로와 헤더 양쪽에 둘 때는 두 곳의 강조를 일치시킨다 — 한쪽만 튀면 어색하다(2026-07-26).
  • 아이콘을 쓰면 라벨과 함께 쓴다(아이콘 단독 버튼은 aria-label 필수 + Tooltip 참조).
Don't
  • arch를 여러 개 나란히 두지 말 것 — 위계가 무너진다.
  • 라임·노랑 단색으로 버튼을 칠하지 말 것(웹) — 제품 지시·아치 내부 전용 색이다.
  • 모서리를 full 외의 값으로 바꾸지 말 것 — 버튼/인풋 형태 구분이 사라진다.
  • 링크로 이동하는 요소를 버튼처럼 꾸미지 말 것 — 이동은 Link, 실행은 Button. (단 앵커가 CTA 역할이면 버튼 스타일 허용 — 홈 실측 관례)

콘텐츠 규칙

  • 라벨은 동사형으로 끝낸다: "견적 요청하기", "카탈로그 받기" (명사 단독 "견적" ✗).
  • 길이는 2~4어절, 줄바꿈 없이 한 줄(white-space: nowrap). 말줄임표(…) 금지.
  • 이중 부정 금지("취소 안 함" ✗ → "유지하기").
  • 조사 오류·띄어쓰기는 발행 전 점검(전역 규칙: ../guidelines/ux-writing.md).

키보드 인터랙션

키동작
Tab버튼으로 포커스 이동(포커스 링 표시)
Enter / Space버튼 실행

접근성

  • 네이티브 <button> 요소를 쓴다(<div role="button"> 지양) — 키보드·스크린리더 기본 지원.
  • 대비: 흰 라벨 대비는 navy(≈14:1)·teal(#0B6C7D ≈4.9:1, AA) 충분. arch는 라임 시작부에서 대비가 약하므로 라벨을 그라디언트의 청록 쪽(중앙~우측)에 걸치게 하고 600 이상 굵기를 유지한다. AA가 필수인 화면(폼 제출 등)은 teal 변형을 쓴다.
  • 포커스 링 제거 금지(:focus-visible + --focus-ring) — 밝은 면·네이비 면·아치 면 셋 다에서 판독돼야 한다.
  • 히트영역: 시각 높이 40px(sm)일 때도 패딩·마진으로 44px(--target-min) 히트영역을 확보한다(웹 실측 40px — design.md Known Gaps #3, 시각 규격은 유지하되 터치 영역으로 보완).
  • 비활성은 disabled 속성(스타일만 흐리게 하지 말 것). 기준: ../guidelines/accessibility.md.
  • prefers-reduced-motion: reduce에서 translateY 호버 모션을 끈다.
