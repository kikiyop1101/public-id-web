# task H2 — 한글 조판·띄어쓰기·표기 규칙 전수 (11-04)

AGENTS.md(표기 규칙·금지 표현)·docs/design-canon.md를 먼저 읽고 따른다. 브랜치+PR.

## 의도
- 문제: 10월 이후 자동으로 올라간 소식·답변·영상 설명과 새 쪽의 문장이 국립국어원 띄어쓰기·회사 표기 규칙(AGENTS.md)에 어긋나는 곳이 남아 있을 수 있다.
- 성공한 모습: 공개 쪽 본문·제목·메타 설명 전수에서 띄어쓰기(조사 붙임·의존명사 띄움·숫자+단위 붙임), 금지 표현(AGENTS.md 목록), 웹 주소 표기(www.public-id.co.kr 하나)가 맞고, 고친 곳 목록(파일·전/후)이 PR에 있다.
- 닿는 곳: `src/` 문구·`content`/데이터 파일·메타데이터. 사실·숫자·제품명·인증 표기는 의미를 바꾸지 않는다.
- 지킬 것·안 할 것: 문장 뜻을 바꾸는 재작성 금지(띄어쓰기·표기만). CSS는 `word-break: keep-all` 등 조판 규칙이 빠진 곳만.
- 가정: 애매한 띄어쓰기는 고치지 않고 PR에 '확인 필요' 목록으로.

## 검증
- 빌드·lint 통과, 고친 곳 표(파일·줄·전→후) PR 본문에.
