# task H5 — SEO·AEO 구조 점검(구조화 데이터·사이트맵·내부 링크·llms) (11-04)

AGENTS.md(클라우드 절·표기 규칙)를 먼저 읽고 따른다. 브랜치+PR. 외부 제출(IndexNow·서치콘솔)은 하지 않는다.

## 의도
- 문제: 쪽이 늘면서 사이트맵·llms-full.txt·구조화 데이터가 실제 쪽과 어긋났을 수 있다.
- 성공한 모습: 빌드 결과 전 쪽에서 깨진 내부 링크 0, 사이트맵에 빠진 공개 쪽 0(일부러 뺀 쪽은 이유 표), JSON-LD 문법 오류·필수 칸 빈 값 0, 제목·설명 길이(제목 ≤60자·설명 ≤160자 안팎) 벗어난 쪽 0, `llms-full.txt`·`/md` 목록이 현재 쪽과 일치.
- 닿는 곳: `src/app/sitemap.ts`·`robots.ts`·`llms-full.txt`·각 쪽 metadata·JSON-LD.
- 지킬 것·안 할 것: 사실(회사 정보·인증·숫자)은 기존 문구에 있는 것만, 서치어드바이저·구글 소유확인 메타태그는 그대로.
- 가정: 검사 스크립트를 `scripts/`에 남겨 다음에도 돌릴 수 있게.

## 검증
- 검사 스크립트 출력(전후), 빌드·lint 통과를 PR 본문에.
